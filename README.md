# Prompt Manager

Python으로 만든 콘솔 기반 프롬프트 관리 프로그램입니다.

## 실행 방법

터미널에서 다음 명령어를 실행합니다.

```bash
python3 main.py
```

## 주요 기능

- 프롬프트 추가
- 전체 프롬프트 목록 조회
- 카테고리별 조회
- 제목 또는 내용으로 프롬프트 검색
- 프롬프트 상세 보기
- 즐겨찾기 추가 및 해제
- 즐겨찾기 목록 조회

## 프롬프트 카테고리

- 텍스트 생성
- 이미지 생성
- 영상 생성
- 페르소나
- 자동화
- 기타

## 데이터 구조

프롬프트는 Python의 리스트와 딕셔너리를 사용하여 관리합니다.
프로그램 실행 중 추가한 데이터와 즐겨찾기 상태는 유지되며, 프로그램 종료 시 초기화됩니다.
